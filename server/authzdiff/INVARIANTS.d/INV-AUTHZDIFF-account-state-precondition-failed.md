- **INV-AUTHZDIFF-account-state-precondition-failed** The three self-service MFA ops with no RBAC gate (`mfa.activate`, `mfa.disable`, `mfa.recovery-codes.regenerate`) are modelled with `requirement.accountState`: a caller that is authenticated and not suspended but lacks the account state (a pending enrolment; `mfa_enabled=true`) gets `PreconditionFailed` from `model.decision`, not `Denied`. `restOutcome` maps a 400 to `PreconditionFailed` only when its body carries a message the op names in `opSpec.preconditionMsgs` (`mfaPreconditionMsgs`: the client-safe `mfaSafeMessages` strings for no pending enrolment and MFA not enabled, "user not found" for a machine token with no account, and "invalid code or password" for the re-authentication refusal on activate); an op naming none keeps every 400 as `Other`, so no other op's outcome moves. A restricted PAT is still `Denied` (403, `patRefusesUngatedWrite`). `classify` treats the vocabulary as closed: a leg answering `PreconditionFailed` against any other model outcome, or a model saying it against a leg answering 200, 403 or `Other`, is an `O2:` or `mapping-gap:` class that no waiver absorbs. This replaced waiver known-12 (#4525), which absorbed every 400 on these ops against a `Denied` model and so could not tell a precondition from a real authorization divergence. Guard: TestV5ext5StrictSweep and the full strict sweep (no waiver matches these ops), TestRestOutcomePreconditionFailed, TestRestOutcomeNoPreconditionWithoutOpMessages, TestPreconditionDivergencesAreUnexplained, TestAccountStateOnlyOnTheMFAOps (server/authzdiff/outcome_precondition_test.go); the plants `mfa-disable-precondition-answers-200` and `mfa-activate-precondition-answers-403` (plants_test.go) prove a handler that answers 200 or 403 for an unmet precondition fails a strict sweep. What it does NOT verify: that the 400 is the right status for the precondition (the status is kept by decision: the request is well formed, the account state is not), the message text beyond the substrings, and any other op's 400.
