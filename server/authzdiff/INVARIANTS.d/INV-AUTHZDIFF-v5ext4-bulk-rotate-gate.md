- **INV-AUTHZDIFF-v5ext4-bulk-rotate-gate** `BulkRotateSecrets` is authorized entirely at the router layer (secrets.write@project, via `RequireScopedPermission(permSecretsWrite, projectScope)` in `server/http/router.go`). The core function takes the acting user ID and refuses a suspended or deactivated account (requireActorActive, #4159), but performs no permission check; the differential harness therefore classifies an active principal as errNotAuthzLayer, excluding it from Oracle 1 (layer-agreement), and takes part only for a suspended principal, which core must refuse (TestCoreRefusesSuspendedActor/bulk.rotate; red when the guard is removed). Removal of the router gate is the only way a caller without secrets.write could rotate secrets in bulk. Guard: TestBulkRotateRouterGatePresent (server/authzdiff/sweep_v5ext4_test.go) — asserts the gate anchor exists in router.go, fails immediately if the line is removed or changed. Red/green proof: remove the anchor → 0 occurrences → test fails; tree as committed → 1 occurrence → test passes.
