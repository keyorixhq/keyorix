- **INV-AUTHZDIFF-v5ext8-9-impersonation-webauthn-gates** Three self-service ops are bound in the cross-layer authorization differential (Stage 3, V5EXT8/9): `impersonation.start` (POST `/api/v1/admin/impersonate`), `impersonation.end` (POST `/api/v1/auth/end-impersonation`) and `webauthn.deleteCredential` (DELETE `/api/v1/auth/webauthn/credentials/{id}`). All three have `core_refusal="none"` (coreEnforced=false): the core leg is recorded but excluded from Oracle 1/2. `impersonation.start` is modelled by its route gate `globalPerms:["users.impersonate"]` (admin-bypass only) + `humanOnly`. `impersonation.end` is modelled by `impersonatingSession` (the bearer's session has `impersonated_by IS NOT NULL`, checked by `model.isImpersonatingSession` via raw SQL against the SHA-256-hashed session token) + `humanOnly` + `accountState`: only `pkImpersonating` (the controlAs positive control, a real session seeded by `StartImpersonation`) is Allowed; a regular session that is not impersonating maps to `PreconditionFailed` (REST 400 "Not an impersonation session", named in `preconditionMsgs`); a machine is `Denied` (handler 403, modelled by `humanOnly`); a PAT bearer is `Denied` (handler 403 "session-only endpoint", modelled because `POST /api/v1/auth/end-impersonation` is in core's restricted-PAT write-refusal table, `patRefusesUngatedWrite`). `webauthn.deleteCredential` is modelled by `mfaRequired` + `accountState`: only `pkMFAUser` (owns the direct-inserted `webauthn_credentials` fixture row and has TOTP) is Allowed; every other principal fails `requireReauth` → `PreconditionFailed` (`mfaPreconditionMsgs`), a PAT is `Denied` (the DELETE route is in the restricted-PAT write-refusal table). The `impersonatingSession` precondition is stripped by `model.decision` alongside the MFA flags when `accountState` is set. Guard: `TestImpersonationStrictSweep` (zero uncalibrated, zero unexplained over the named principals) and the router-anchor tests `TestImpersonateStartRouterGatePresent`/`TestEndImpersonationRouterGatePresent`/`TestDeleteWebAuthnCredentialRouterGatePresent`. Red proof (committed, `plants_test.go`, CI job `authzdiff-plants`): `impersonation-start-rest-gate-removed` (removes the route gate → non-admins reach the admin-rank ceiling → 500 → unexplained), `impersonation-end-session-check-removed` (accepts any regular session → 200 where the model denies → unexplained), `webauthn-delete-credential-error-swallowed` (swallows the reauth error → 200 where the model says PreconditionFailed → unexplained) — each produces many unexplained cases with the overlay and zero without. What it does NOT verify: the session-auth refusal path on impersonation.start (actorCtx defaults sessionAuth true); the cookie-swap "Return to Admin" flow; `requireEqualOrGreaterAdminAuthority` when the impersonation target holds admin roles; session expiry; the WebAuthn passkey assertion path (webauthnRP is nil in the harness); and `BeginWebAuthnRegistration`/`ListWebAuthnCredentials` (deferred).
