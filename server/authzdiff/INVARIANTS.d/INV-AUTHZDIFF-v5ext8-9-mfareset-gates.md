- **INV-AUTHZDIFF-v5ext8-9-mfareset-gates** Three MFA-reset ops are bound in the cross-layer authorization differential (Stage 4, V5EXT8/9): `mfaReset.cancel` (POST `/api/v1/mfa-reset-requests/{id}/cancel`), `mfaReset.request` (POST `/api/v1/mfa-reset-requests`) and `mfaReset.approve` (POST `/api/v1/mfa-reset-requests/{id}/approve`). All three are REST-only, `coreEnforced=false` (core leg recorded, excluded from Oracle 1/2), and `globalHandler=true` (served through package-level handler globals; the REST leg re-points them under `routerMu`, checked by `TestGlobalHandlerFlagMatchesRouter`). For all three the route gate `RequirePermission(permUsersWrite)` → `users.write@global` is WEAKER than the core's effective gate (an admin-named role at global scope, plus — for request/approve — the actor's own second factor): HARDENING-V5EXT8/9-1, a route-vs-core gap documented in the report, NOT a reachable bypass (core always runs after the route and enforces the stronger check). The model captures the effective gate: `mfaReset.cancel` = `globalAdminRole + humanOnly` (positive control pkGlobalAdmin); `mfaReset.request`/`mfaReset.approve` = `globalAdminRole + humanOnly + mfaRequired` (positive control pkMFAResetActor, a global admin with a plaintext-seeded TOTP secret; request targets `freshUserID`, approve targets a pre-seeded request `mfaResetRequestV9ID` requested by a second admin so dual control holds). `mfaRequired` here is modelled as a PLAIN deny (no `accountState`): the "admin without a second factor" refusal is `ErrMFAResetActorNeedsMFA` → HTTP **403** (a hard denial), not a 400 precondition — this is the key re-derivation onto main's stricter `classify`, which (unlike the base these ops were written against) flags a Denied-vs-PreconditionFailed pair as unexplained. Guard: `TestMFAResetStrictSweep` (zero uncalibrated, zero unexplained over the named principals plus the curated `pkCustom` with `users.write@global` but no admin role, which is refused at core — 403 Denied — where the model agrees, making the HARDENING gap an observable Denied rather than a silent pass) and the three router-anchor tests.
