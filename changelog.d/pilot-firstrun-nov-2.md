### Fixed
- **`keyorix system init` with no `--admin-email` now works.** The default was `admin@localhost`, which the server's email rule refuses, so a bare `system init` always failed. The default is now the placeholder `admin@keyorix.local` (it has no mailbox: pass your own address to receive password-reset mail), and `--help` says so.
- **`POST /system/init` answers rejected admin details 400, not 403.** A malformed email or username from a caller who holds the bootstrap token now returns 400 with the typed code `ValidationError` and `details.field` naming the input. A wrong or missing bootstrap token, and a server with no token configured, are still 403, and the token is still checked before the details, so the answer tells a caller without the token nothing about validation. `keyorix system init` prints the validation text with the flag to fix (`--admin-email`, `--admin-username`) instead of the "ask a project admin / request access" hint; it recognises the same refusal from a server that still answers it 403.
