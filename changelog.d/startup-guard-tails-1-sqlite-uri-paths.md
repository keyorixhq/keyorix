### Security
- **A SQLite database given as a `file:` URI is now pre-created at mode 0600 and migration-locked like its plain path.** `storage.database.path: file:/data/secrets.db` (or `file:///...`, `file://localhost/...`, percent-encoded) made the server pre-create a junk relative `file:/data/...` path, so the real database was born at the process umask until the post-open permission check corrected it, and a process on the URI and one on the plain path took different migration locks on the same database. The database file, its `-wal`/`-shm` permission check and the migration lock now resolve the path with the same rules as the server lock sidecar, and only a `file:` URI's query string (`mode=memory`) marks a database in-memory: a directory named `mode=memory` is a real directory, and a plain path with `?mode=memory` (the driver drops a plain path's query) is the real file, so it now gets the 0600 pre-create, the server lock sidecar and the migration lock.
