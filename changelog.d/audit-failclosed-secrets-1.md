### Security
- **Secret mutations commit their audit row in their own transaction, tagged or not (#4719).** A secret mutation reached without a transport's audit tag used to commit with no audit row: REST bulk rotate and the rotation scheduler stored new versions with no `secret.rotated` row at all. Core now derives the row itself (attributed to the call's actor, or `system`), so rotate (on demand, bulk, scheduled), copy, the CLI's embedded bulk delete, folder create, classify, bulk rename, extend-expiring, move and ownership transfer commit nothing when their row cannot be written (REST: 503 `audit_unavailable`, bulk operations: a per-item failure). The scheduler's `secret.rotate_backend_started` row is now required before an upstream backend is called. Guarded by `TestSecretMutationAudit_UntaggedCallCommitsItsRowOrNothing` and `TestBulkRotate_EachRotationCommitsItsSecretRotatedRow`.
- **Auto-rotation config, secret dependencies, retention overrides and environment clone/copy are audited fail-closed (#4718, secrets rows).** Each change and its row commit together; unbinding a rotation backend is a revocation and is never blocked by the audit log (its row is owed). Clone and copy-environment write the new `environment.clone_started` / `environment.secrets_copy_started` row before copying anything. Guarded by `TestSecretsAuditRows_ChangeCommitsWithItsRowOrNothing`.
- **Compliance evidence, audit-log CSV and access-log exports are audited before delivery (#4721).** New events `audit.exported`, `secret.access_log_exported`, `compliance.evidence_delivery_failed`; `compliance.evidence_exported` is now written before the pack is delivered (REST download included). A refused row sends nothing (503 `audit_unavailable`, "nothing was exported, retry"); the scheduled export retries on its next tick. The JSON SIEM pull feed `GET /api/v1/audit/export` stays unaudited on purpose (ADR-112).
