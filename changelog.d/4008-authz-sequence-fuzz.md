### Testing
- **Stateful authz sequence fuzzing.** `server/authzdiff` gains `FuzzAuthzSeq` and an opt-in sweep (`AUTHZSEQ_SWEEP=1`) that run random sequences of grants, revokes, group changes, suspensions and permission toggles on the core, REST and gRPC legs, and compare every step and every probe with the reference model. A transport allowing what the model denies, an allowed step whose effect is missing (a revoke that did not revoke, a suspension or membership change that did not happen), a denied step that changed state, and a step on which a transport answers a server error (5xx, gRPC `Internal`) always fail; they are never treated as single-step noise. The fuzz target and the sweep share one triage, and the planted-defect tests assert that it fails. One known-open gRPC error-mapping gap (#4020: `RemoveRole`/`AssignRole` answer `Internal` where REST answers 404/409) is tolerated by its exact signatures only, with the state still required unchanged. The default `go test` runs the baseline, one benign sequence and two planted defects (`revoke-noop`, `revoke-noop-held`); `AUTHZSEQ_SELFTEST=1` runs the rest. The reference model's group-role resolution now treats a project-scoped group membership as conferring the group's roles only in that project, which matches the store's group-role resolution.
