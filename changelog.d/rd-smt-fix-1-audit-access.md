### Security

- New `keyorix-migrate vault audit-access` (read-only) lists Keyorix grants that `keyorix-migrate` v0.96.0–v0.96.3's `apply-access` created wider than their source Vault policy (a policy path narrower than the project/environment it was mapped to, or a stanza's `list` granted as `secrets.read`: `list`-only and KV v2 `metadata/` stanzas, and write stanzas that also list, such as `["create", "update", "list"]`) and that a migrated machine identity still holds, each with the API call that revokes exactly that grant; it exits 1 when it finds any, and also when the audit is incomplete because a Vault input could not be read or the Keyorix token cannot see every project (`--json` reports `complete: false`). Installs that ran `apply-access` with those releases should run it with the same flags (docs/UPGRADING.md §6w).
