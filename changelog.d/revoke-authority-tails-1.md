### Security
- **Leases issued from a dynamic-secret config that now has a refused `admin_dsn` option can be revoked again (#3980).** Since #3952 the use-time refusal of options that make the driver read the server's files (MongoDB `tlsCAFile` and the other `tls*File` / `ssl*File` options, PostgreSQL `sslrootcert`, `sslcert`, `sslkey`, `passfile`, MySQL `allowAllFiles`) also ran on revoke, so every revoke and expiry sweep of an already-issued lease failed and the lease stayed `revoke_failed`. MongoDB and MySQL users have no native expiry, so they stayed live on the target. Revoke now connects without those options and never reads a local file; issue and renew still refuse the config. Without its CA file the connection verifies against the Keyorix host's system trust store (PostgreSQL `sslmode=require` with a root certificate is verified as `verify-ca`, `sslrootcert=system` as `verify-full`, as before), so for a target signed by a private CA, add that CA to the host's system trust store. Revoke still refuses options that change the target or the credential: PostgreSQL `service` / `servicefile`, a PostgreSQL DSN without its own password (the password came from a passfile), and MongoDB `authMechanism=MONGODB-OIDC` / `MONGODB-AWS` / `GSSAPI`. **To find affected configs:** list each config's leases (`keyorix dynamic-secret leases <config-id>`, or `GET /api/v1/dynamic-secrets/configs/{id}/leases`) and look for `status: revoke_failed`; the audit log has a `dynamic_lease.revoke_failed` event per failed attempt, and an issue from an affected config fails with an error naming the refused option. After upgrading, the next sweep revokes expired ones; `POST /api/v1/dynamic-secrets/leases/{leaseID}/revoke` or `POST /api/v1/dynamic-secrets/configs/{id}/revoke-all` drops the rest. A config that still cannot revoke keeps the lease `revoke_failed`: drop its user on the target by hand. Guarded by `TestRevokeExpiredLeases_StoredConfigWithRefusedOptionStillRevokes`, `TestPostgresRevoke_StoredConfigWithRefusedOptions`, `TestMongoRevoke_StoredConfigWithRefusedOptions`, `TestMySQLRevoke_StoredConfigWithAllowAllFiles`, `TestPostgresRevokeDSN_NeverLowersVerification` and `TestEveryRefusedOptionHasARevokeDecision`.
