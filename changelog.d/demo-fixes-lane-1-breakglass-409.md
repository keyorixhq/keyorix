### Fixed
- **A second "Request emergency access" while one is active now answers 409 with the reason, not 500.** `POST /api/v1/projects/{id}/break-glass` (and `BreakGlassService.ActivateBreakGlass`, now `AlreadyExists`) returned `500 "an internal error occurred"` when the caller already held an active break-glass grant on the project, although the server log had the clean message; the web UI showed "Something went wrong". It is now `409` with "you already have an active break-glass grant on this project; revoke it before activating again", which the UI shows.
