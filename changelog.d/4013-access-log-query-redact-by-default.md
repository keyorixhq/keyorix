### Security
- **Access log redacts query-string values by default.** The access log (text and JSON formats and the panic-context line) now logs a query value only for an allowlisted parameter (pagination, sorting, enumerations, numeric and time identifiers) and only when the value is a short plain token (1 to 64 of `A-Za-z0-9_.:-`). Every other value, including anything with `%`, `;`, `/` or `+`, is logged as `[redacted]`, so a secret placed in a URL query no longer reaches the logs. Operators lose the query values of other parameters in the access log. Guarded by `TestRedactSensitiveURI_QueryRedactedByDefault`, `TestRedactSensitiveURI_AllowlistedValueShapeChecked` and `TestLogger_NeverLogsArbitraryQuerySecret`.
