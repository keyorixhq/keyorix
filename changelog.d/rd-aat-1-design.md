### Documentation
- **Attenuating agent tokens: design (R&D, not implemented).** ADR-120 (Proposed) adopts draft-niyikiza-oauth-attenuating-agent-tokens-02. Keyorix would issue a root token when an agent session starts (aligned with the agent evidence ledger design, PR #3668). Agents derive narrower tokens offline, and a verified chain only narrows the agent's roles and the delegator's current permissions at the `Authorize` chokepoint. Design note `docs/design-rd-aat.md`: the profile, the SMT encoding that proves the attenuation rules sound (each rule shown to be needed), the prototype results against the draft's published vectors, and the implementation plan. Threat rows: `docs/security/threat-models/agent-delegation-tokens.md`, all GAP. Demo script (future CLI): `docs/demo/attenuating-agent-tokens.md`.
