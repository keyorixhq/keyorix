### Testing

- **Soak harness with resource-growth oracles (`server/soak`).** A seeded mixed workload drives the real `server/http` router (login/logout, secret create/read/update/delete/list, project and environment churn, audit read, failed-auth, malformed requests, client disconnects and timeouts) while a sampler records goroutines (grouped by stack), heap after GC, file descriptors, `database/sql` pool stats, temp files and bookkeeping-table row counts. Three oracles read the series: slope per 1000 requests against a calibrated threshold (report-only), return-to-baseline of goroutines, descriptors, in-use DB connections and temp files after an idle drain (hard), and no goroutine stack absent at baseline unless allowlisted with a reason (hard). The oracles were red-proofed with planted leaks (`server/soak/testdata/redproof/run.sh`). A one-minute smoke runs on SQLite (`KEYORIX_SOAK=smoke`); the long mode (`scripts/fuzzing/soak/run-soak.sh`) is meant for pve01, on SQLite or PostgreSQL. The default `go test ./server/soak` runs only the oracle unit tests. Tests and scripts only: no product code changed.
