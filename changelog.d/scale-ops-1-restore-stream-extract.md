### Fixed
- **`admin restore` no longer holds a whole table in memory while unpacking the archive.** The archive reader read each table's NDJSON entry into a single buffer before checking its size and checksum, so a restore's peak memory grew with the largest table (the audit log is usually the largest). It now copies each entry to the staged file through a bounded buffer while hashing it, with the same per-entry and total size limits, size and checksum checks and path rules; nothing past a limit is written to the staging directory. Guarded by `TestExtractArchive_TableEntryIsStreamed`.
