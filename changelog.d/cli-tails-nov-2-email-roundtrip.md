### Fixed
- **CLI refuses an email it cannot send unchanged (#4797).** The oapi-codegen runtime (still so in v1.9.1) decodes `"a b"@example.com` to `a b@example.com`, which its own encoder then rejects, and it silently rewrites a quoted local part or a `Name <addr>` typed on the command line into a different address. `user create`, `user update`, `invite send` and `system init` now check `--email` / `--admin-email` before any request and fail with one usage error naming the flag (exit 2); a plain `name@domain.tld` is unchanged. Guard: `cli/cmd/emailflag_test.go`, `cli/cmd/user_email_roundtrip_test.go` (the latter pins the runtime defect, so it fails when an upgrade fixes it).
