### Fixed

- **Web: the New Role and Edit Role forms work again.** They sent an empty permission list, which the server refuses, so every Create and Save failed with a generic error. The forms now carry a permission checklist (at least one on create; on edit the permissions are sent only when changed), require a description, and show the server's own message.
- **Web: Edit Role no longer offers a change the server refuses.** The "Can be granted" selector is disabled, with a short explanation, for built-in roles. The web's built-in role list now matches the server's, so the named project and system roles (such as `project_viewer`) are treated as built-in too.
- **Web: dark theme text contrast.** `--text-muted` is now `#92929d` (4.5:1 or better on every dark surface; it was 2.7 to 3.8:1). Status badges and messages on the System Health, Authentication, Notification Channels, Roadmap and Dashboard pages, the token revoke control and the share dialog use the `--success`, `--warning` and `--danger` tokens instead of fixed hex colours, so they follow the theme. A structure test (`hardcodedTextColours.test.ts`) fails when one of those hex colours returns or a new hard-coded text colour is added.
