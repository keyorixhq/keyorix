### Fixed
- **Eighteen more column-scoped writes store UTC on a non-UTC host.** Writes that update a single column or a set of columns skip the model hooks and GORM's UTC clock, so they stored the server's local time zone: share, project, secret, template, rotation-policy, escalation-policy and dynamic-secret-config `updated_at`, break-glass `revoked_at`/`reviewed_at`, lease `revoked_at`, setup-token `consumed_at`, session `rotated_at`, secret `last_rotated_at`/`cert_not_after`, machine-identity reactivation `updated_at` and the scheduler lock's `expires_at`. On SQLite those values did not sort against the UTC timestamps written everywhere else. They are now stored in UTC. Guarded by `TestHookBypassTimeWriters_StoreUTCOnNonUTCHost`, which runs under `TZ=Asia/Kolkata` on SQLite and Postgres.
