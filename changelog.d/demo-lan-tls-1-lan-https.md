### Added
- **One-command HTTPS demo box for a LAN or an air-gapped network.** `deploy/demo-lan/install.sh --bin-dir <linux binaries>` creates a local CA once (ECDSA P-256, 10 years, X.509 nameConstraints limited to the box's own address and names), signs the server certificate with it (825 days or less, re-issued automatically when fewer than 30 days are left), starts a fresh server on `0.0.0.0` with TLS, seeds the demo org through https and ends with `scripts/demo/check.sh --used`. It prints the CA file, its SHA-256 fingerprint and the trust commands for macOS, Windows and Linux; trusting the CA once in each browser is the only manual step. No ACME, no public DNS, no manual openssl. Refuses to run over an existing `keyorix.db` unless `--reuse`, and deletes nothing. See `docs/demo/LAN-TLS.md`.

### Testing
- **Tests for the LAN demo installer.** `deploy/demo-lan/demo_lan_test.go` checks the generated CA and certificate with openssl only (name constraints, SAN, key modes, validity, the 30-day renewal threshold, a certificate for another name is rejected), the installer's refusals, run-time address detection, that no lab address is committed, and that the files `install.sh` copies cover what `check.sh` calls.
