### Documentation
- **FINDING doc template and regression-test traceability checker.** `docs/findings/TEMPLATE.md` establishes the canonical structure for new finding docs, including a required `**Regression test:**` metadata field. `TestFindingRegressionTests_NamedTestsExist` (`internal/docsdrift`) verifies every finding doc that carries this field names a `Test…`/`Fuzz…` function that actually exists in the stated package, and requires the field on every FINDING doc dated 2026-11-27 or later. Older FINDING docs without the field are grandfathered (skipped and counted in the test log). CLAUDE.md "Writing a FINDING doc" section documents the workflow.
