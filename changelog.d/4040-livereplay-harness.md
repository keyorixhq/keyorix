### Testing
- **Live-server authorization replay harness.** `scripts/e2e/livereplay` (build tag `e2e`) boots a throwaway `keyorix-server`, records a legitimate project-admin session and replays it and every `/api/v1/*` OpenAPI operation as other principals (another tenant's admin, a lower role, no grant, machine tokens, no or bad credentials), with swapped and mutated object ids. Three deny-direction oracles (status, cross-tenant leak, observable state change) are judged against a small authorization model. The state oracle calibrates its own snapshots for self-induced drift and requires a change to persist. Planted-defect self-tests run in the default `go test` (fake API) and against the real server (`TestLiveReplay_PlantedDefects`). A run fails, rather than reporting a null result, when a fingerprint path stops answering 2xx, a request gets no HTTP answer, the server exits, or seeding cannot create a fixture.
