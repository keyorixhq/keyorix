### Testing

- **Oracle-backed fuzz targets for `internal/secretenv`** (previously had no `func Fuzz` at all, despite being on the security-sensitive list). Six targets, each with a sound, one-directional oracle and a red/green proof: `FuzzCheckInfoNeverAcceptsUnsafe` and `FuzzCheckOwnerFailClosed` (the key-material permission/owner classifier never accepts an unsafe file), `FuzzTrimOneTerminator` (strips exactly one line terminator), `FuzzDescribeFileNoRelativePathLeak` (a relative secret-file path is never echoed), `FuzzLookupPrecedenceFailClosed` (both `X` and `X_FILE` set is a hard error, never a silent resolve), and `FuzzReadSecretFileRoundTrip` (the read path is bounded, refuses an empty secret, and round-trips the content). The properties are formalised as new `INV-SECRETENV-*` fragments linked to these guards. Test-only; no product-code change.
