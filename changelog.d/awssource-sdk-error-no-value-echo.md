### Security
- **`keyorix-migrate` no longer puts an AWS Secrets Manager response body into its error text.** When the SDK cannot decode a response, its error quotes the body, and for `GetSecretValue` that body is the secret value, so the value could reach whatever prints or logs the importer's error. When the SDK received a response, the AWS importer now reports the HTTP status only, as the Azure importer already does; transport failures (refused connection, DNS, deadline) keep their cause. Guarded by `TestList_SDKErrorDoesNotEchoResponseBody`.
