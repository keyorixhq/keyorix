### Security
- **The secret list no longer shows ACL-granted secrets to a user who has left the project.** A per-secret or per-folder ACL grant is listed only while its grantee is still a member of the secret's project, the rule authorization already applied. Before, a user whose only project role was revoked (or who lost a group-only membership) could still list the secret's name, description, metadata, classification and owner, and with a folder grant every descendant secret; secret values were never readable. Guarded by `INV-CORE-acl-listing-honours-live-membership` (#4623).
