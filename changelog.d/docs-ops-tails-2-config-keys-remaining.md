### Documentation
- **`docs/CONFIGURATION.md` documents `auto_rotation`.** `auto_rotation.enabled`, `schedule` (default `1h`) and the `backends[]` keys `name`, `type`, `region` and `allowed_refs` now have a section: the backend types, that `allowed_refs` is required (a backend without it is refused at start) and how its prefix match works. `connect.connectors[].environment` is documented as reserved and not enforced.
- **The four legacy `client.*` keys are listed as exempt, with a reason.** The server ignores `client.endpoint`, `timeout`, `auth.type` and `auth.api_key` (the pre-ADR-108 CLI's connection settings). `internal/docsdrift/testdata/undocumented_config_leaves.txt` now requires `<key> <reason>` on every line that stays on it.
