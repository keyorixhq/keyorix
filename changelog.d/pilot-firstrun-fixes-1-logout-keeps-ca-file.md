### Fixed
- **`keyorix logout` no longer deletes your `ca_file` and server URL (#3735).** Logout revokes the session on the server and removes only the token (and the active project) from the CLI credentials file, rewriting it at 0600; the next `keyorix login` against a private-CA server works without running `keyorix config set ca_file` again, and `--server` can be omitted. `keyorix login` also checks the server's TLS certificate before it asks for the password, and a certificate failure now says to set `ca_file`.
