# internal/delivery invariants

Rules a change in this package must keep. New invariants go in
`INVARIANTS.d/INV-DELIVERY-<slug>.md` (one per file); see
`docs/invariants-fragments.md`.

Format: `INV-DELIVERY-NN <rule>. Why: <source>. Guard: <test> | UNGUARDED (#issue)`.
