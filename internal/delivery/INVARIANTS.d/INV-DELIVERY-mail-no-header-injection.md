- **INV-DELIVERY-mail-no-header-injection** The setup-link message built by `buildMessage` (smtp.go) and serialised by go-mail `Msg.WriteTo` has a header-field multiset, To-recipient count and MIME-part count that depend only on which optional fields are set, never on the *bytes* of the attacker-influenced recipient / install-name / display-name / message / assignment-summary / link — so CRLF or MIME-boundary bytes in those fields can never add a header, recipient or MIME part. Why: ADR-028 credential delivery; CRLF/header-injection is the classic SMTP formatting attack (ML1 campaign, piece 1). Guard: `FuzzMailSetupLinkInjection` (`internal/delivery/mail_injection_fuzz_test.go`) — structural-equality oracle vs a benign baseline, parsed with net/mail + mime/multipart.
