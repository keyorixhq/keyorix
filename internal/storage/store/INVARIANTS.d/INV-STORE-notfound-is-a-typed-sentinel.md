- **INV-STORE-notfound-is-a-typed-sentinel** A `LocalStorage` getter that maps `gorm.ErrRecordNotFound` to "not found" returns an error that matches a typed sentinel (`internal/core/storage/errors_notfound.go`, `storage.NotFound`) and only for that definitive case; a driver or connection error never matches it. Callers classify errors with `errors.Is` on a sentinel, never by message text: the text is translated (de/es/fr/ru), so a text match turns a real 404 into a 500 under a non-English locale. The rendered text is unchanged. Guard: `TestLocalStorage_NotFoundSentinels`; `internal/core/storage` `TestNotFound_KeepsTextAndMatchesSentinelAndCause`.
