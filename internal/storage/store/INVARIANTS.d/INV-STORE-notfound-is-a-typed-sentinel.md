- **INV-STORE-notfound-is-a-typed-sentinel** Each `LocalStorage` getter listed in `TestLocalStorage_NotFoundSentinels` (notification channel, machine credential by ID, OIDC binding, connector project binding, secret template by ID and name, share and share lock, SSO login state, permission, alert escalation policy, rotation policy), plus `ConsumeSSOLoginState`'s lost-race branch (`TestConsumeSSOLoginState_LostRaceIsTheSameNotFound`), returns an error that matches a typed sentinel (`internal/core/storage/errors_notfound.go`, `storage.NotFound`) on a definitive not-found and only then; a driver or connection error never matches it. The rendered text is unchanged. Callers of these getters classify errors with `errors.Is` on the sentinel, never by message text: the text is translated (de/es/fr/ru), so a text match turns a real 404 into a 500 under a non-English locale. Scope: this is NOT yet true of every getter. Known exceptions still returning an untyped not-found: `GetProject`, `GetProjectByName`, `GetEnvironment` (`local_secrets.go`) and the secret ACL getters, owned by ERRLOSS-MFA-1 / ERRLOSS-ACL-1. The guard covers the listed getters only: no family-wide check fails CI when a new or unlisted getter returns an untyped not-found, so add a row to the test with every converted getter. Guard: `TestLocalStorage_NotFoundSentinels`, `TestConsumeSSOLoginState_LostRaceIsTheSameNotFound`; `internal/core/storage` `TestNotFound_KeepsTextAndMatchesSentinelAndCause`.
