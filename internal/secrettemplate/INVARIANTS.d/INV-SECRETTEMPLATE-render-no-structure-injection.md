- **INV-SECRETTEMPLATE-render-no-structure-injection** A resolved secret value substituted by `RenderJSON` cannot change the rendered JSON document's key-set (it stays exactly the template's own keys), and a value substituted by raw `Render` cannot add an output line — any value that could (newline/CR/NUL or a shell metacharacter) is rejected by the render-time guards instead of being emitted. Why: a secret value is set by whoever can write that one secret, who may be far less trusted than the template's author or the file's consumer (render.go's documented threat model); ML1 campaign, piece 2. Guard: `FuzzSecretTemplateRenderStructure` (`internal/secrettemplate/render_structure_fuzz_test.go`) — JSON key-set + raw line-count structural-equality oracle. Complements `FuzzParse`, which guards the parser.
