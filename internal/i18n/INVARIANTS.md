# internal/i18n invariants

Rules a change in this package must keep. New invariants go in
`INVARIANTS.d/INV-INTL-<slug>.md` (one per file); see
`docs/invariants-fragments.md`. The prefix is `INV-INTL` (not `INV-I18N`): the
invariant-ID format requires a letters-only package tag.

Format: `INV-INTL-NN <rule>. Why: <source>. Guard: <test> | UNGUARDED (#issue)`.
