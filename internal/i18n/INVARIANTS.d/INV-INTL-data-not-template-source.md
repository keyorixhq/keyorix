- **INV-INTL-data-not-template-source** `Localizer.Localize` renders a message in a single pass: `TemplateData` values are substituted as values and are NEVER re-parsed as go-i18n/text-template source, the call never panics for any (messageID, data), and an unknown message ID returns the ID verbatim. Why: defense-in-depth — today all call sites pass hardcoded IDs and nil data and x/text printf formatting is unused, but a future call site forwarding user data must not become a template-injection or panic surface (ML1 campaign, piece 3). Guard: `FuzzI18nLocalizeFormat` (`internal/i18n/i18n_inject_fuzz_test.go`) — output compared to an independent single-pass text/template execution.
